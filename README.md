# 🎉 Teacher's Day Letter for Sir Randy Bello

## 💌 Project Description

This project is a special interactive Teacher's Day greeting letter created for **Sir Randy Bello**, our Web Development teacher.

The website combines **HTML, CSS, and JavaScript in a single HTML file**. It features animations, a digital letter, a cake theme, fireworks, and a dark/light mode switch.

The purpose of this project is to express appreciation and gratitude to Sir Randy Bello for his guidance, patience, and dedication in teaching Web Development.

## ▶️ How to Run the Project

1. Download or copy the project file.
2. Locate:

```text
teachers-day-randy-bello.html
```

3. Double-click the file.
4. The website will open in your default web browser.

You can also open it using:

* Google Chrome
* Microsoft Edge
* Mozilla Firefox
* Opera

---

## 💻 How to Edit the Message

Open the HTML file using a code editor such as:

* Visual Studio Code
* Notepad
* Notepad++
* Sublime Text

Find the letter section:

```html
<div class="letter" id="letter">
```

You can change the message inside this section to personalize the letter.

---

## 🌙 Dark / Light Mode

The website includes a theme switch located at the top-right corner.

Click:

```text
🌙 Dark Mode
```

to switch to dark mode.

Click:

```text
☀️ Light Mode
```

to return to light mode.
